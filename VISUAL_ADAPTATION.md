# Visual adaptation record

Source: https://hermes-agent.nousresearch.com
Workflow: https://github.com/promptwhisper/clone-any-website-skill

The requested adaptation reuses a visual direction: cobalt field, condensed display typography, silver hero object and editorial frame. ArenaCover has its own branding, copy, original generated shield, locally bundled open fonts and transaction dashboard. No source bundle, Hermes mark, trial font or analytics is copied.

The skill verifier captured desktop 1440×900 and mobile 390×844. This is an intentional approximation: original artwork, content and spacing differ, so pixel equivalence gates fail. They were not relaxed. Runtime reported zero console errors, zero page errors and zero requests to the target origin. Two request failures occurred during capture; this is not reported as an overall pass. Separate Chromium QA confirmed no mobile horizontal overflow and the recording completed all four confirmed transactions without page errors.

The initial serif version used Bodoni Moda; after the user's review, the 60-second revision uses stronger Bebas Neue titles and numbers with faster mask, wipe and camera transitions. Interface display typography uses Barlow Condensed; supporting text uses IBM Plex Mono. Font licenses are bundled.
